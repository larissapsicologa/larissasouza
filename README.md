# Site de Psicologia - Larissa Cristina Oliveira de Souza

Site estático (um único arquivo `index.html`).

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub (ex.: `psilarissa`).
2. Envie todos os arquivos desta pasta (descompactados) para o repositório.
3. Vá em Settings > Pages > Source: "Deploy from a branch" > branch `main` / pasta `/ (root)` > Save.
4. Em alguns minutos o site fica em `https://SEU-USUARIO.github.io/psilarissa/`.

## Editar dados
Abra `index.html` e altere o bloco `CONFIG` perto do final do arquivo.
